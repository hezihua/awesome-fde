> **课程来源**：FDE 实战训练营第一期 · 第 02 节
> **时长**：约 1 小时 59 分
> **核心问题**：给企业做 AI 服务，到底交付什么？

## 一、客户一定会问的三句话

1. 我们公司用 AI，能得到什么
2. 要用什么样的工具
3. 怎么用起来

市面上交付很乱：SaaS、垂直 Agent、通用 Agent、一体机、咨询、培训、小工具定制都有。课程教的不是「永远用某一个模型」，而是一套**几年甚至更久都未必过时的框架**。

两个月前 GLM 还是国内最强 Agent 模型，很快 Kimi K3 又上来。**模型吞噬一切**：去年用 n8n / 扣子搭的 Workflow，会被清洗进训练数据，下一代模型自己就会搭。工具会过时，框架要稳住。

## 二、AKA 框架

**Agent + Knowledge / Database + Automation**

| 字母 | 含义 | 解决什么 |
| --- | --- | --- |
| **A · Agent** | 能干活的 AI | 不只是网页对话框 |
| **K · Knowledge / Database** | 清晰上下文 | 知道公司怎么干活 |
| **A · Automation** | 自动化 | 让它自己去干 |

这套组合被认为能覆盖企业 AI 落地约 **80%** 的问题。模型怎么换，三个部件还在。

## 三、Chatbot 和 Agent 差在哪

客户常觉得：不过是把 DeepSeek / 豆包从网页搬到本地。要讲清楚：

- **Chatbot**：网页对话，你复制粘贴，它回文字
- **Agent**：能控制电脑。能写代码 ≈ 能操作文件系统、浏览器、办公软件，也就能接管大量「坐在办公室点鼠标」的白领工作

给老板演示的最短路径：打开 Claude Code / Codex / WorkBuddy，让它在本机执行一条命令，对方立刻理解「这不是换皮聊天框」。

## 四、2026 年怎么选

国际看 **Codex** 和 Claude Code（后者封号严重，课上更推 Codex）。国内基本盘是 **WorkBuddy**：

- 适配飞书 / 企微 / 钉钉，不用从零手搓连接
- 数据不出境，符合很多公司的合规红线
- 同一水平线的国产竞品几乎没有

海外产品抄 Codex 时，三个板块几乎都会有：

1. **插件市场**：Skillhub、MCP、CLI
2. **项目 / 工作空间**：沙箱隔离
3. **自动化**：定时任务

WorkBuddy 的「专家团 / 技能」就是 Skill 市场。企业版往往同时收 **Token 费 + 按人头订阅**。

## 五、选型原则

- 国央企、强监管：本地部署或国产闭环
- 大多数国内公司：**不必再造一个 Agent 产品**，市面模型和产品已经够用
- 教框架，不绑死某一个模型名。模型三个月一变，AKA 的三个部件不变
- 给客户讲价值时，先演示「能控制电脑」，再讲知识库和自动化，对方才听得进去
