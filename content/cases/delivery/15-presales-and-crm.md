## 一、这期课怎么收尾

前面偏执行：搭库、跑工作流、拆价格带。这一节补「单子怎么进来、怎么收得住」。课后会再收问题、安排集中答疑，并整理作业和线下面谈，谈后续合作。

权益（线下参训、后续项目）以当时训练营公告为准。这里记的是可复用的方法。

## 二、售前要管的不是 PPT

售前顾问要能回答：

- 这个客户处在千元 / 万元 / 十万哪一档
- 拍板人是谁（第 4 节）
- 买的是培训、定制还是陪跑
- 哪些能写进售前方案，哪些必须留到执行方案

客户档案从第一次接触就建：来源、行业、预算体感、已经用过的工具、反对者是谁。第 13 节的表格，首先是给自己用的。

## 三、合同和验收

企业单最容易烂在「做完了但没说清什么叫完」。最低限度写清：

| 条款 | 为什么要写 |
| --- | --- |
| 项目周期 | 陪跑按月，培训按天，不要混成一笔糊涂账 |
| 验收标准 | 多少人完成实操、哪条工作流稳定跑通 |
| 验收时间 | 避免无限改需求 |
| 数据与保密 | 对应第 6 节：设备、权限、退出 |
| 分成 / 协作 | 训练营强调白纸黑字，项目里同样适用 |

咨询公司、部门负责人、员工代表，三边预期经常不一致。合同是把三边拉到同一张纸上。

## 四、项目进度怎么让客户安心

- 客户档案、项目进度、负责人，分三张表或三个视图
- 每周给拍板人看进度，不给所有人看同一份过细的日志
- 工作流挂了先修，再解释原理——客户买的是结果

## 五、一期训练营的闭环

```
市场与能力（01）
  → 选型与 AKA（02–03）
  → 组织与商业（04–05）
  → 合规（06）
  → 名词与装库（07–09）
  → 自动化与部署（10–11）
  → 价格带案例（12–14）
  → 售前与客户管理（15）
```

回去能做的最小动作：选一个真实客户或自己的公司，按 AKA 写一页诊断，再决定它是千元、万元还是十万的故事。
