## 一、为什么先拆千元档

周末线下反馈：实操还要再多。于是提前把模拟实战拉到线上，用脱敏案例走完整流程。沟通课和更硬的工程（把 Vibe Coding 做稳）后面用录播补。

千元档卖的不是「一个大模型账号」，而是一条**能周更的内容生产线**：

```
产品图 / 参考图 → 选题与标题 → 文案 → 配图 / 视频 → 发布与风控
```

生成「好看帖子」的具体配方是商业机密，课上只要求建立判断：这件事情成立，且能用 AKA 装起来。

## 二、典型交付物

- 飞书云文档 / 多维表格：选题、标题、状态
- 文案知识库：客户口吻、禁词、过往爆款
- 浏览器工作流：打开后台、抓数据、辅助发布
- 图视频模型：出效果图，而不是从零手绘

客户要的是「我给产品图，你能稳定出帖」，不是再听一遍提示词课。

## 三、风控是这个档位的命门

小红书对账号、IP、设备、发布节奏敏感。FDE 方案里必须写：

- 账号矩阵怎么隔离
- 哪些步骤能自动，哪些必须人手点
- 标题和素材如何避免模板脸

只追求产量、不管风控，交付当天好看，第二周账号没了。

## 四、这一档能教会学员什么

- 把模糊需求收成一条流水线
- 用知识库锁住品牌语气
- 用最低配的自动化换时间，而不是上重型中台
