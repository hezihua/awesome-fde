> **时长**：约 1 小时 15 分
> **关键词**：飞书、客户档案、权限、销售、数据管理

## 一、和昨天的差别

千元档：电商参考图 → 生成小红书帖。万元档还是 **Agent + 知识库 + Skill**，但客户要的是「能管起来的系统」，不是一条内容流水线。

课上演示用的是上个月的 demo，并不完善——这本身也是实话：万元档卖的是结构和权限，不是完美产品。

## 二、客户档案为什么值这个价

销售型团队的痛点通常是：

- 客户信息散落在微信和个人备忘
- 上市公司客户和普通客户混在一个表格
- 新人无法接手老人的关系

万元档常见交付：

| 模块 | 作用 |
| --- | --- |
| 客户档案表 | 编号、来源、阶段、负责人 |
| 权限 | 老板看全量，销售看自己的盘，普通人看不到敏感字段 |
| 知识库 | 话术、案例、产品说明 |
| Skill | 从聊天 / 会议纪要回写档案 |

飞书多维表格 + 权限，对中小公司已经是「管理系统」，不必先上独立 CRM。

## 三、加载和治理

「数据加载」听着工程，落地就是：历史 Excel、名片、聊天记录如何进表，重复客户如何合并，谁有权改阶段。第 3 节的四个标准在这里全部适用：可追溯、可理解、可控制、可相信。

业务部门要的是自己能改；你要防止改乱。方案里把字段字典和权限矩阵写清楚，比多做两个炫酷 Agent 更值钱。

## 四、报价逻辑预告

第 14 节会把话说死：5 万和 50 万经常干同一件事，差在买家支付能力和销售说服。万元档是中间态——客户愿意为「档案 + 权限 + 培训」多付一截，但还没到集团培训预算。
